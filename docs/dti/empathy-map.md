### Detailed Breakdown

1. **SAYS**:
   - Expresses desire for straightforward 1-click plan cancellation.
   - Demands clear payment transaction reference logs.
2. **THINKS**:
   - Wonders whether recurring plans are cost-effective.
   - Values clear status badges (`ACTIVE`, `EXPIRED`, `CANCELLED`).
3. **DOES**:
   - Searches for plan features and duration details before subscribing.
   - Evaluates active subscriptions periodically.
4. **FEELS**:
   - Annoyed when billing dates pass without warning.
   - Empowered when given full control over activation and renewal.
5. **PAINS**:
   - Lack of expiry warnings.
   - Complex account deletion workflows.
6. **GAINS**:
   - SubTrack dashboard displaying current plan, start date, expiry date, status badge, and instant action buttons.
