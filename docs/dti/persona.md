### 1. Anonymous Identifier & Demographics
- **Identifier**: `Respondent-A04`
- **Age Range**: 22–28 years
- **Role**: Software Developer & Tech Enthusiast

### 2. Goals & Needs
- **Goals**: Wants total clarity and control over subscription lifecycles.
- **Needs**: Transparent billing, instant mock payment processing status, and easy renewal/cancellation controls.

### 3. Frustrations & Pain Points
- Subscription platforms requiring customer support calls to cancel.
- Unclear expiration dates leading to unexpected charges.

### 4. Behavioral Traits & System Expectations
- Expects modern glassmorphic web dashboard with responsive action buttons (`Activate`, `Renew`, `Cancel`).
- Values JWT-based secure authentication and quick API responses.
